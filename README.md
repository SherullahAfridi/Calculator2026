# Scientific Calculator Android App

A scientific calculator application for Android, developed using Kotlin and Android Studio. The application provides a calculator interface for basic arithmetic and scientific operations.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Trigonometric functions: sin, cos, and tan
- Logarithmic functions: log and ln
- Powers, square roots, factorials, and reciprocal calculations
- Parentheses, percentages, and absolute value
- Mathematical constants: π and e
- Degree mode and additional scientific calculator controls

*Note: Feature availability depends on the implemented functionality in the current version.*

## Technology Stack

- **Language:** Kotlin
- **Development environment:** Android Studio
- **Layouts and resources:** XML
- **Build system:** Gradle
- **Version control:** Git and GitHub

## Getting Started

1. Install Android Studio and the required Android SDK.
2. Clone the repository:

   ```bash
   git clone https://github.com/SherullahAfridi/Calculator2026.git
   ```

3. Open the project in Android Studio.
4. Allow Gradle synchronization to finish.
5. Start an Android emulator or connect an Android device.
6. Click **Run** to launch the application.

This project demonstrates Android development with Kotlin, UI resource management, calculator logic, Gradle project configuration, and Git version control.
